# Finora — приватный менеджер личных финансов

Finora — это локальное приложение для учёта личных финансов с открытым исходным кодом,
предназначенное для развёртывания на собственном компьютере. Оно помогает понять, куда уходят
деньги, планировать бюджеты, контролировать счета и выявлять закономерности расходов.

## Основные принципы

- Приватность прежде всего — данные хранятся только локально (SQLite на вашем компьютере).
- Необязательная регистрация и отсутствие облачных аккаунтов.
- Нет интеграции с внешними финансовыми API и нет внешней аналитики.
- Никакой рекламы и скрытой передачи данных.
- Надёжные финансовые расчёты (целочисленные minor единицы валюты, без бинарных float).
- Полный контроль над экспортом и резервным копированием данных.
- Сервер привязан к `127.0.0.1` по умолчанию (не доступен извне).

## Стек технологий

- Python 3.11+
- FastAPI
- SQLAlchemy 2.x (async)
- SQLite (файловая база в `app/data/finora.db`)
- Alembic (миграции)
- Jinja2, HTML5, CSS3, Vanilla JavaScript
- pytest, Ruff

## Возможности

- Управление счетами (наличные, банк, сбережения, кредит, произвольные) с балансами.
- Доходы, расходы и переводы между счетами (переводы не считаются доходом/расходом).
- Категории доходов и расходов с цветами, иконками и архивацией.
- Бюджеты: месячные и по категориям, выполнение, остаток, индикатор превышения.
- Повторяющиеся транзакции (ежедневно, еженедельно, ежемесячно, ежегодно, свой интервал)
  с защитой от дублей.
- Дашборд: общий баланс, доходы, расходы, чистый денежный поток, сравнение с предыдущим
  периодом, расходы по категориям, недавние транзакции, обзор счетов.
- Фильтрация, поиск, сортировка и пагинация транзакций.
- Экспорт и импорт CSV с сопоставлением колонок и предварительным просмотром.
- Резервное копирование и восстановление (JSON-архив всей базы).
- Поиск по описаниям и заметкам.
- Локализация: русский (по умолчанию) и английский; светлая и тёмная тема.
- CSRF-защита, валидация ввода, ограничение размера загружаемых файлов.

## Архитектура

Модульная структура:

```
app/
  config.py         конфигурация (переменные окружения)
  database.py       двигатель/сессия SQLAlchemy
  models/           ORM-модели (счета, категории, транзакции, бюджеты, повторения, теги)
  repositories/     доступ к данным
  services/         бизнес-логика (денежные расчёты, переводы, отчёты, импорт/экспорт, бэкапы)
  api/              HTTP-маршруты FastAPI
  middleware/       CSRF-защита
  templates/        Jinja2-шаблоны интерфейса
  static/           CSS и JS (i18n, общая логика, графики на Canvas)
  locales/          файлы переводов (ru, en)
  migrations/       Alembic-миграции
  data/             рабочая директория с базой SQLite (создаётся при запуске)
```

Все денежные суммы хранятся в виде целых единиц меньшей единицы валюты (копеек), что
исключает ошибки бинарной арифметики с плавающей точкой.

## Установка и запуск (Windows PowerShell)

```powershell
# Клонируйте или скопируйте репозиторий
cd C:\Users\nu11\Documents\GitHub\Finora

# Создайте виртуальное окружение (рекомендуется)
python -m venv .venv
.venv\Scripts\Activate.ps1

# Установите зависимости
pip install -r requirements.txt

# Первый запуск
python -m uvicorn app.main:create_app --factory --host 127.0.0.1 --port 8000
# или, после установки пакета:
finora
```

При первом запуске база данных инициализируется автоматически (`app/data/finora.db`).
Откройте в браузере `http://127.0.0.1:8000/`.

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `FINORA_HOST` | `127.0.0.1` | Адрес привязки сервера |
| `FINORA_PORT` | `8000` | Порт сервера |
| `FINORA_BASE_CURRENCY` | `USD` | Базовая валюта (3 буквы) |
| `FINORA_CURRENCY_SYMBOL` | `$` | Символ валюты |
| `FINORA_DEFAULT_LANGUAGE` | `ru` | Язык по умолчанию |
| `FINORA_DATA_DIR` | `app/data` | Директория данных |
| `FINORA_DATABASE_FILE` | `finora.db` | Имя файла базы |
| `FINORA_DEBUG` | `0` | Режим отладки |

## Тестирование

```powershell
pip install -r requirements.txt
pytest
```

Тесты используют изолированные временные базы SQLite и синтетические данные.
Внешние сайты и API не задействуются.

## Резервное копирование и восстановление

- Создание копии: раздел «Резервное копирование» → «Создать копию» (JSON-файл в `app/data`).
- Скачивание и восстановление из файла с обязательным подтверждением.
- Перед восстановлением копия проходит валидацию; рабочая база заменяется атомарно.

## Безопасность и конфиденциальность

Приложение предназначено для локального единоличного использования. Оно не является
многопользовательской банковской платформой и не претендует на банковскую сертификацию.
Сервер привязан к `127.0.0.1`, финансовые данные не передаются за пределы компьютера,
аналитика и телеметрия отсутствуют.

## Ограничения

- Поддерживается одна базовая валюта для аналитики (мультивалютность не реализована).
- Повторяющиеся переводы между счетами не поддерживаются (только доход/расход).
- Это локальное приложение, не рассчитанное на одновременную работу нескольких пользователей.
